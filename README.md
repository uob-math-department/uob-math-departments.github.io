# The Math Escape Challenge

Orientation Day hub page for the Department of Mathematics.

- `index.html`: hub with Home / Challenge / Form tabs and a QR code button
- `challenge.html`: the game (self-contained)
- `qr.html`: printable QR code poster (open it on the live site and print)

To change the Google Form, edit the `data-src` (embed URL ending in `?embedded=true`)
and the "Open in Google Forms" link in `index.html`.

Hosted for free on GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
